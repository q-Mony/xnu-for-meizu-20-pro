第五轮诊断状态区刷新节流：真实生产函数测试（Nova）

本目录为新测试交付物，无旧版。当前阶段仅准备验收计划；生产接口由主任务提供后，再从 BootLog.c 等已完成源码提取真实函数与依赖声明。不会把测试内重写的节流器当作生产实现。

测试边界：主任务拥有生产修改及设备操作；本目录只放 host harness、运行脚本、提取片段、日志与结果。硬件计时器、帧缓冲和中断现场通过受控替身输入；节流状态机和受测入口保持生产源字节。host 结果不等于真机显示成本或中断行为验证。

待接口确定后执行的验收项：

1. 首次有效状态绘制立即发生；同一时刻及不足一秒的重复请求被跳过，恰好一秒边界允许绘制。
2. IRQ/FIQ 与线程来源共用同一预算；交错请求不会分别获得一秒额度。
3. busy 与 inactive 情况不消费成功绘制额度、不更新首次有效绘制状态；解除该条件后仍能按原预算绘制。
4. 计时器跨 uint64 回绕时保持约定的一秒比较；零起点可用。另检查不存在时间倒退下的算术未定义行为，具体倒退策略以生产接口契约为准。
5. 替身绘制函数推进受控时钟，验证完成绘制次数、累计 elapsed、最大 elapsed；跳过、未激活、busy 请求不计为成功绘制。确认 elapsed 的计量边界与汇总字段单位。
6. 用真实中断入口或与基线的有限差异核对，证明节流前后的 IRQ/FIQ 计数和现场采样更新仍执行；不能用“绘制次数少了”代替采样不丢的验证。
7. 非阻塞 gate 的递归/竞争情况不会等待、重复绘制或错误释放他人的 gate；报告读取若与绘制交错，按接口声明的快照语义验证。
8. 汇总入口只在线程上下文输出，拥有明确间隔及总量上限；中断绘制路径不调用 printf。无变化是否抑制以及失败重试是否消费预算，以接口契约固定后测试。
9. 将受测函数从提取片段移除或还原为旧版，验证 harness 不能仍然通过；运行编译告警与 ASan/UBSan，明确替身及并发覆盖的限制。

待主任务提供：受测函数/状态名称、两来源入口、时钟单位与预算起算点、inactive 定义、绘制与汇总计数口径，以及可提取的源码边界。
