## 完整性

- timestamped原件和派生正文分别保存；source-map记录字节范围，inline前缀也可回指。
- 非法/未知版本前缀保留原文；零频率的结构完整前缀可剥离，但不能参加时间计算。
- P/L/R仅表示规定的提交点；裸字符和无标签行没有时间，不沿用最近标签。
- CNTVCT前缀、Mach阶段ns及旧日志内部计量分别保留，不借频率跨时钟域相减。
- 未标明的采集缺失不能由文本自行排除；旧分析报告仅消费派生正文，不能替代新时间证据。
